# Biblioteca de marcas da FGF

Fonte: [Marcas oficiais da FGF](https://fgf.com.br/marcas/). Baixado em 01/10/2026.

Os arquivos em `originais/` foram preservados exatamente como recebidos. Os PNGs das quatro categorias iniciais também estão nesta pasta principal. Os pacotes ZIP mantêm as versões oficiais, inclusive vetores quando fornecidos.

As cópias WebP mantêm os pixels e a resolução dos PNGs. `variantes/` organiza as versões horizontais, verticais, coloridas e monocromáticas presentes nos pacotes. Apenas a imagem usada na próxima partida é carregada pelo site.

`catalogo.json` registra a URL oficial, o original, as dimensões das imagens, as variantes e os nomes cadastrados em `js/desempenho.js`. Outros layouts podem escolher uma variante usando `logoCompeticao` no JSON da categoria.

## Edições específicas

O pacote `Gauchao25.zip` foi reservado como Gauchão 2025. A página chama o pacote da Copa Sul de 2026, mas a arte mostra 2025; por isso, o cadastro automático usa `Copa Sul 2025`. Os festivais possuem arquivos separados para a 2ª e a 3ª edição. Para uma nova edição, confirme a marca fornecida pela FGF antes de reutilizar a anterior.
